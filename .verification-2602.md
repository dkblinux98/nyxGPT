**Streaming Protocol** (`src/mygpt/chat.py:391-406`):
- RAG metadata emitted as first chunk
- Format: `__RAG_START__{json}__RAG_END__\n`
- JSON structure:
  ```json
  {
    "type": "rag_metadata",
    "chunks": [
      {
        "text": "...",
        "score": 0.95,
        "doc_id": "doc1",
        "chunk_id": 0
      }
    ]
  }
  ```
