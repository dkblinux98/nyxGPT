Acceptance-perspective classification. The 168 issues labeled Acceptance Failure (defects found at stakeholder acceptance, before release) are classified by root cause: escaped defect — broken behavior in code that had passed review (a review miss); spec gap — the delivered work matched the issue but the requirement itself was wrong or incomplete (redesigns, consolidations, UX corrections); workflow miss — the agent pipeline itself failed (review gate, branch hygiene, submission workflows). Classification is keyword-heuristic over titles and bodies, hand-reviewed. No issue carries a Production Defect label.

Sprints. The Sprint field lives in the GitHub Project (iteration field), which is not readable through the API surface available here. Sprints on this page are therefore derived from the calendar: one-week sprints starting Monday, numbered from the project's first week (Sprint 1 = week of Dec 29, 2025), bucketing issues by creation date. If the real sprint cadence differs, the numbering can be re-mapped without changing the underlying data. Milestones are the repo's phase milestones, ordered. The six issues under the "Phase X: Rejected" milestone (rejected, never worked) are excluded throughout.

Review gate. Monthly counts of PRs with ≥1 REQUEST_CHANGES come from the complete GitHub notification-email archive (thread-level, so a PR rejected in two months counts in both); merged-PR counts from the GitHub API. Feb shows more rejected than merged because rejected PRs often merged in a later month or were superseded.

Last 7 days. The 41 REQUEST_CHANGES reviews on nyxGPT PRs between 2026-07-23 and 2026-07-30, parsed from the structured review comments (Critical / Medium / Minor findings sections). Re-review rejections with no new findings count as a round with zero findings. Of 67 PRs merged in the window, 11 owner-carried workflow merges bypassed agent review and are excluded from first-pass stats; of the 57 reviewed PRs (56 merged + #3450 still in review), 30 were approved first-pass — verified against each PR's review history. Module attribution follows the repo's module taxonomy, inferred from issue titles (the Project's Module field is not API-readable here). PR #3398 has no linked issue and is listed under its PR number.
