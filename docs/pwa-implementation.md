# Progressive Web App (PWA) Implementation

## Overview
nyxGPT is now a full-featured Progressive Web App with offline support, install prompts, and push notification foundations.

## Features Implemented

### 1. Web App Manifest
Enhanced manifest with comprehensive PWA metadata:
- Multiple icon sizes for different devices (192x192, 512x512)
- Both "any" and "maskable" icon purposes for better adaptation
- App categories (productivity, utilities, education)
- App shortcuts for quick actions
- Screenshots for app store listings
- Proper orientation and display settings

**File**: `web/public/manifest.json`

### 2. Install Prompt
Intelligent install prompt component that:
- Captures the `beforeinstallprompt` event
- Shows a custom install UI with better UX than browser default
- Remembers user dismissal for 7 days
- Automatically hides if app is already installed
- Respects user choice (accepted/dismissed)

**Component**: `web/src/components/PWAInstall.tsx`

**Features**:
- Fixed-position banner at bottom of screen
- Install and dismiss buttons
- Styled with app theme colors
- Uses localStorage for dismissal tracking
- Checks `display-mode: standalone` media query

### 3. Splash Screen
Configured via manifest icons:
- Uses PWA icons for splash screen generation
- Background color: `#ffffff`
- Theme color: `#0070f3`
- Automatically generated by browser

### 4. Push Notifications
Foundation for push notifications with Web Push API:

**Component**: `web/src/components/PushNotifications.tsx`

**Features**:
- Permission request UI
- Subscription management
- VAPID key integration (placeholder)
- Subscribe/unsubscribe functionality

**API Routes** (Placeholders for backend integration):
- `/api/push/vapid-public-key` - Returns VAPID public key
- `/api/push/subscribe` - Stores push subscriptions
- `/api/push/unsubscribe` - Removes push subscriptions

## Installation Experience

### Desktop
1. User visits the site
2. Install prompt appears after a few seconds (if not dismissed recently)
3. Click "Install" button
4. Browser shows native install dialog
5. App installs to OS application menu
6. Can be launched like a native app

### Mobile (Android/iOS)
1. Visit site in Chrome/Safari
2. See "Add to Home Screen" prompt or install banner
3. Tap "Install" or "Add"
4. App icon appears on home screen
5. Launches in standalone mode (no browser UI)

## Push Notifications Setup

Push notifications require backend infrastructure. Here's how to complete the implementation:

### 1. Generate VAPID Keys

```bash
npx web-push generate-vapid-keys
```

This generates a public/private key pair:
```
Public Key: BEl62iU...
Private Key: f7rZnY...
```

### 2. Store Keys Securely

Add to your environment variables (`.env.local`):
```
VAPID_PUBLIC_KEY=your_public_key_here
VAPID_PRIVATE_KEY=your_private_key_here
VAPID_SUBJECT=mailto:your-email@example.com
```

### 3. Update API Routes

Update `/api/push/vapid-public-key/route.ts`:
```typescript
export async function GET() {
  return NextResponse.json({
    publicKey: process.env.VAPID_PUBLIC_KEY,
  });
}
```

### 4. Implement Subscription Storage

Choose a storage backend:
- **Database**: PostgreSQL, MySQL (recommended for production)
- **Redis**: Fast, in-memory storage
- **File system**: Simple, for development only

Example schema:
```sql
CREATE TABLE push_subscriptions (
  id SERIAL PRIMARY KEY,
  endpoint TEXT NOT NULL UNIQUE,
  p256dh TEXT NOT NULL,
  auth TEXT NOT NULL,
  user_id INTEGER,
  created_at TIMESTAMP DEFAULT NOW()
);
```

Update `/api/push/subscribe/route.ts`:
```typescript
export async function POST(request: NextRequest) {
  const subscription = await request.json();

  await db.insertSubscription({
    endpoint: subscription.endpoint,
    p256dh: subscription.keys.p256dh,
    auth: subscription.keys.auth,
  });

  return NextResponse.json({ success: true });
}
```

### 5. Send Push Notifications

Install the web-push library:
```bash
npm install web-push
```

Example notification sender:
```typescript
import webpush from "web-push";

webpush.setVapidDetails(
  process.env.VAPID_SUBJECT,
  process.env.VAPID_PUBLIC_KEY,
  process.env.VAPID_PRIVATE_KEY
);

async function sendNotification(subscription, payload) {
  try {
    await webpush.sendNotification(subscription, JSON.stringify(payload));
  } catch (error) {
    if (error.statusCode === 410) {
      // Subscription expired, remove from database
      await db.deleteSubscription(subscription.endpoint);
    }
  }
}
```

### 6. Service Worker Notification Handler

Add to your service worker (`public/sw.js` is auto-generated, create `public/sw-custom.js` for custom logic):

```javascript
self.addEventListener("push", (event) => {
  const data = event.data.json();

  event.waitUntil(
    self.registration.showNotification(data.title, {
      body: data.body,
      icon: "/icon.png",
      badge: "/icon.png",
      data: data.url,
    })
  );
});

self.addEventListener("notificationclick", (event) => {
  event.notification.close();
  event.waitUntil(
    clients.openWindow(event.notification.data)
  );
});
```

## Usage Guide

### For Users

**Installing the App**:
1. Visit the site
2. Look for the install banner at the bottom
3. Click "Install"
4. Find the app in your applications

1. Go to Settings or Profile page
2. Click "Enable Notifications"

**Testing Install Prompt**:

## Security Considerations

### VAPID Keys
- Store private key securely (environment variables, secrets manager)
- Never commit private key to version control
- Rotate keys periodically

### Subscriptions
- Associate subscriptions with user accounts
- Implement rate limiting on notification endpoints
- Validate subscription data before storing
- Clean up expired subscriptions

### Permissions
- Request notification permission contextually (not on page load)
- Respect user's notification preferences
- Provide easy way to disable notifications

## Troubleshooting

### Install Prompt Not Showing
- Ensure manifest is valid (check DevTools > Application > Manifest)
- Verify service worker is registered
- Check that app isn't already installed
- Clear localStorage key `pwa-install-dismissed`

### Push Notifications Not Working
- Verify VAPID keys are configured
- Check service worker registration
- Ensure HTTPS (required for push notifications)
- Check browser console for errors

### Service Worker Not Updating
- Hard refresh (Ctrl+Shift+R or Cmd+Shift+R)
- Unregister service worker in DevTools
- Clear site data and reload
